# Tools

## Website and TLS scanners

- [Sucuri SiteCheck](https://sitecheck.sucuri.net/): malware, blacklist and outdated software check
- [Mozilla Observatory](https://observatory.mozilla.org/): site security configuration check
- [Qualys SSL Labs](https://www.ssllabs.com/ssltest/): TLS configuration test
- [ImmuniWeb](https://www.immuniweb.com/free/): free application and website tests
- [Pentest-Tools](https://pentest-tools.com/): web vulnerability scanners and more
- [UpGuard WebScan](https://webscan.upguard.com/): website risk scan
- [HostedScan](https://hostedscan.com/): hosted vulnerability scanning
- [Quttera](https://quttera.com/): website malware scanner

## DNS, mail and network

- [Zonemaster](https://www.zonemaster.net/domain_check): DNS domain check
- [EasyDMARC](https://easydmarc.com/tools/dmarc-lookup): DMARC lookup
- [Have I Been Pwned](https://haveibeenpwned.com/): breach lookup
- [YouGetSignal](https://www.yougetsignal.com/): network tools
- [SecurityTrails style utilities (suip.biz)](https://suip.biz/): online network utilities

## Utilities

- [YAML Lint](http://www.yamllint.com/): YAML validator
- [DigiCert CSR tool](https://www.digicert.com/easy-csr/openssl.htm): OpenSSL CSR generator
- [CIRT default passwords](https://cirt.net/passwords): default credentials database
- [Kali Tools](https://en.kali.tools/): Kali tool index
